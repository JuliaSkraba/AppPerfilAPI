# 👤 App Perfil API

Aplicação desenvolvida em **React Native** com **Expo**, criada para consumir uma API e apresentar informações de perfil de forma organizada e visualmente agradável.

O projeto foi desenvolvido durante minha formação em tecnologia, com o objetivo de praticar desenvolvimento mobile, consumo de APIs e construção de interfaces utilizando React Native.

---

## 📱 Sobre o projeto

O **App Perfil API** apresenta informações de um perfil através de uma interface mobile.

A aplicação foi desenvolvida para praticar a integração entre **frontend e backend**, realizando o consumo de dados por meio de uma API.

---

## ✨ Funcionalidades

- 👤 Exibição de informações do perfil
- 🎓 Exibição de formação acadêmica
- 💻 Apresentação de habilidades e tecnologias
- 💼 Exibição de experiências
- 🔗 Integração com API
- 📱 Interface desenvolvida para dispositivos móveis

---
